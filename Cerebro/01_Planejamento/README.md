# 01_Planejamento

Antes de executar qualquer tarefa complexa, a IA deve criar um plano de ação aqui.

## Formato de um Plano
```markdown
# Plano: [Nome da Tarefa]
**Data:** YYYY-MM-DD
**Status:** Pendente | Em Progresso | Concluído

## Objetivo
Descrever claramente o que será feito.

## Etapas
1. [ ] Etapa 1
2. [ ] Etapa 2

## Riscos
- Possíveis problemas e como mitigá-los.

## Resultado Esperado
O que deve existir no Workspace ao final da execução.
```
