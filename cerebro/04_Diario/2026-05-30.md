## Nova dimensão arquitetural — Qwen 0.5B como Mini-Agente Auxiliar Supervisionado

**Registrado via sessão Claude · 30/05/2026**

Além da arquitetura do Enxame (delegação de complexidade), identificamos uma segunda camada de uso do Qwen 0.5B: o modelo local operando como **auxiliar de micro-tarefas sob supervisão direta de uma IA externa** (Claude, Antigravity, Manus) durante a execução de tarefas complexas no workspace.

### O problema que isso resolve
Quando uma IA externa (ex: Claude) recebe uma tarefa complexa como o Milestone 4, hoje ela executa TUDO sozinha — gasta muitos tokens, faz operações no workspace, lê arquivos, escreve código, valida — um ciclo longo e caro em um único agente.

### O novo modelo de execução colaborativa
- A IA externa mantém o **raciocínio pesado**: planejamento, arquitetura, decisões de lógica complexa
- O Qwen 0.5B opera como **mini-agente local de workspace**: lê arquivos, executa scripts simples, aplica edições pontuais, valida outputs, move arquivos, roda comandos shell
- O fluxo segue o protocolo: Planejamento → Tarefa → Execução → Memória → Memória RAG
- A IA externa **supervisiona e valida** cada micro-tarefa antes de avançar — o Qwen não toma decisões autônomas

### Ganhos concretos
- Redução de tokens gastos pela IA externa (não precisa ler arquivo para verificar — Qwen lê e reporta)
- Execução paralela de operações de workspace enquanto a IA externa raciocina o próximo passo
- O celular passa a ser um participante ativo da execução, não apenas um terminal de entrada
- Aproveitamento máximo do Qwen 0.5B dentro de suas capacidades reais: operações determinísticas e de baixa ambiguidade

### Limite de operação do Qwen nesse modelo
- SIM: ler arquivo e retornar conteúdo, executar script já existente, aplicar diff/patch, mover/criar/deletar arquivo, rodar comando shell e retornar stdout
- NÃO: decidir arquitetura, debugar lógica complexa, escrever algoritmo novo, interpretar erro ambíguo

## Especificação crítica — Mini-Agente universal via MCP

**Registrado via sessão Claude · 30/05/2026**

O canal de comunicação com o Qwen 0.5B como mini-agente auxiliar de workspace **NÃO é exclusivo do Claude**.
Qualquer IA externa conectada ao sistema via MCP deve ter acesso a essa funcionalidade.

### IAs contempladas (atual e futuras)
- Claude Desktop
- Antigravity
- Manus.IA
- Qualquer nova IA que se conecte via MCP ao sistema

### Implicação arquitetural
O Qwen 0.5B não deve ser exposto como uma ferramenta de uma IA específica.
Ele deve ser registrado como uma **ferramenta MCP do sistema** — disponível no tool_registry.json como um servidor MCP local acessível por qualquer cliente conectado.

Exemplo de entrada no registry:
```json
{
  "name": "workspace_agent",
  "description": "Mini-agente local para micro-tarefas de workspace. Use para: ler arquivos, executar scripts existentes, aplicar patches, rodar comandos shell e retornar stdout. NÃO use para raciocínio complexo ou decisões de arquitetura.",
  "endpoint": "http://localhost:PORT/agent",
  "type": "mcp_tool"
}
```

Assim, quando qualquer IA externa solicitar execução no workspace, ela pode delegar ao agente local da mesma forma — sem depender de qual IA está na sessão.
