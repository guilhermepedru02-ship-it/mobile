## Investigações e Fixes

### Fix 1 — SSID `<unknown ssid>` no Hub PWA

**Hipótese descartada:** Permissão `ACCESS_FINE_LOCATION` ausente no Termux:API.  
**Causa real confirmada:** Android bloqueia acesso ao SSID para processos Node.js em background no momento do boot, antes da stack de rede completar. `termux-wifi-connectioninfo` chamado diretamente retorna `Família Moreno` consistentemente em sessão interativa.

**Dois problemas no código original:**
1. `d.ssid.substring(0, 12)` — truncava qualquer SSID a 12 chars (`<unknown ssid>` virava `<unknown ssi`)
2. Nenhum tratamento para o caso `<unknown ssid>` — exibia o valor bruto

**app.js evolução:**
- v1.0.1 (2026-06-02): Fix CORS via proxy
- v1.0.2 (2026-06-03): Remove substring(0,12), adiciona `isUnknown` handler
- v1.0.3 (2026-06-03): Corrige hint enganoso “ative Localização” → exibe `rede Wi-Fi` + IP sem hint

### Fix 2 — pip3 no Termux

**Estado real:** pip3 NÃO está 100% quebrado. Funciona para pure Python. Falha para C-extensions.
- `pip3 install requests/flask` → ✅ funciona
- `pip3 install numpy/Pillow` → ❌ falha (precisa compilar C)
- Solução: `pkg install python-numpy`, `pkg install python-pillow`
- Instalados na sessão: numpy 2.4.4, Pillow 12.2.0 (scipy já estava via pkg)
