## Testes de Segurança
- ✅ Requisição SEM token → 401 Unauthorized
- ✅ Requisição COM token → 200 OK com dados do Kanban
- ✅ Túnel SSH → URL pública gerada (`serveousercontent.com`)

## Decisões tomadas
- **Serveo > Ngrok:** O binário nativo do Ngrok é incompatível com Android/Termux (`e_type: 2`). A solução final foi **Serveo.net via SSH puro** — zero dependências externas, funciona nativamente.
- Cron abandonado em favor de `/noticias` sob demanda via bot do Telegram.
- Claude via HTTPS Nativo: Decidido usar a lib HTTPS nativa do Node em vez do Axios no Chronos, para minimizar o peso do bot.
- Backup: Escolhida estratégia de redundância. `.tar.gz` diário do Cérebro via Telegram, combinado com backup manual assíncrono do Workspace inteiro via Google Drive, evitando exposição de chaves privadas no Github.
- Postergação do teste com IAs Web (Anthropic Web) para o futuro (tarefa pendente).
