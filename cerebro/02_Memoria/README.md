# 02_Memória Persistente

Esta pasta armazena **contexto de longo prazo** que a IA deve consultar entre sessões.

## Tipos de Memória
- `preferencias_usuario.md` — Gostos e padrões do usuário.
- `decisoes_tecnicas.md` — Decisões de arquitetura já tomadas.
- `erros_conhecidos.md` — Problemas já encontrados e suas soluções.

> A IA deve atualizar esses arquivos sempre que aprender algo novo sobre o projeto ou o usuário.
